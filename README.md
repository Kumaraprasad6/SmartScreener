# ScreenTimeAI

An iOS app that turns your Screen Time data into honest, actionable insights — powered entirely on-device.

## What it does

Most people have a rough sense they spend too long on their phone. ScreenTimeAI makes that concrete: it reads your real usage data, surfaces patterns you haven't noticed, and suggests what you could do with the time you reclaim.

- **Daily dashboard** — total screen time, top apps, and one AI-generated insight about your day
- **Trends** — weekly and monthly usage charts, week-over-week comparisons, daily averages
- **Top apps** — ranked by usage across daily / weekly / monthly views
- **Declutter** — surfaces apps you haven't touched in weeks so you can decide whether to keep them
- **Suggestions** — on-device AI generates a few concrete alternatives for the time you're saving
- **Sync** — account-backed history so your trends survive a reinstall

## How it works

All sensitive data stays on your device. ScreenTimeAI uses Apple's `DeviceActivity` and `FamilyControls` APIs to read usage — the same system that powers the built-in Screen Time dashboard. Only aggregated totals (e.g. "Instagram: 3.2 hrs, Tuesday") are ever written to the cloud; raw activity never leaves your phone.

AI insights are generated by Apple's on-device Foundation Models, so nothing goes to an external inference server either.

## Tech stack

| Layer | Choice |
|---|---|
| UI | SwiftUI |
| Screen Time data | `FamilyControls` + `DeviceActivityReport` |
| On-device AI | Apple `FoundationModels` |
| Local storage | SwiftData |
| Accounts + sync | Supabase (Sign in with Apple) |
| Architecture | MVVM + service-protocol layer |
| Linting | SwiftLint |

## Requirements

- iOS 18.1+ (Foundation Models requires A17 Pro / M-series chip)
- Devices below iOS 18.1 / without Foundation Models support receive template-based insights and are otherwise fully functional
- Screen Time permission is requested on first launch
